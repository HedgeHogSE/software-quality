# Моделирование качества ПО (Web App)

Веб-приложение для моделирования качества программного обеспечения на основе системной динамики (модель ISO).

## Особенности

- **100% статика** - работает прямо из браузера без сервера
- **Быстрый старт** - откройте `index.html` в любом браузере
- **Графики и таблицы** - визуализация результатов моделирования
- **5 реализаций** - выбор разных начальных условий

## Как запустить

1. Откройте файл `index.html` в любом современном браузере
2. Выберите реализацию (начальные условия)
3. Настройте параметры (интервал, шаг)
4. Нажмите "Запустить модель"

## Математическая модель

### Форма уравнений (модифицирована)

В исходной лабораторной правая часть имела вид `du_i/dt = (A_i − B_i) / u_i`. Такая
запись не ограничивает решение: значения уходили и в минус, и выше единицы
(на скриншоте лабораторной радиальная ось доходит до −1.7 … 2.9). Поэтому форма
изменена на логистическую:

```
du_i/dt = k · [ (1 − u_i)·P_i − u_i·N_i ]
P_i = max(A_i, 0) + max(−B_i, 0)
N_i = max(B_i, 0) + max(−A_i, 0)
```

- `P_i − N_i = A_i − B_i` — знак и величина влияний сохранены;
- при `u_i = 0` производная `= k·P_i ≥ 0`, при `u_i = 1` — `−k·N_i ≤ 0`,
  поэтому значения не выходят за [0, 1] (проверено на 5 реализациях,
  случайных начальных условиях и разных шагах);
- деление на `u_i` убрано (оно давало сингулярность, но не ограничивало значения);
- `k` (`EQUATIONS.RATE`) — коэффициент скорости, на инвариант не влияет.

Дополнительно произведения f-множителей считаются как **геометрическое среднее**:
коэффициенты 180 из 187 функций неизвестны (`f(x)=x`), и обычное произведение
15 множителей давало ~3·10⁻⁵ против ~0.1 у трёх множителей, делая уравнения
односторонними. Геометрическое среднее уравнивает вклад независимо от числа множителей.

### Переменные состояния (28 штук)

### Функции модели
- Линейная: f(x) = a*x + b
- Квадратичная: f(x) = a*x² + b*x + c
- Кубическая: f(x) = a*x³ + b*x² + c*x + d

### Внешние возмущения
- Fak1: Опыт разработчиков (t², нормировано из t² + 1)
- Fak2: Опыт эксплуатантов (cos²)
- Fak3: Трудоёмкость (sin(sin))
- Fak4: Курс рубля (t, нормировано из 2t − 1)
- Fak5: Репутация разработчиков (sin²)
- Fak6: Репутация эксплуатанта (гармоническая)

## Использование

### Вкладка "Параметры"
- Выберите одну из 5 реализаций (разные начальные условия)
- Настройте временной интервал (по умолчанию [0, 1])
- В блоке «Функции модели» — семь слотов, как в панели «Уравнения»: в каждом можно выбрать любую из функций f1…f187 (выпадающий список) и отредактировать коэффициенты её многочлена; формула показывается рядом. По умолчанию выбраны семь функций из лабораторной (F3, F5, F9, F48, F72, F81, F117), остальные тождественные. Изменения действуют со следующего запуска
- Нажмите "Запустить модель"

### Вкладка "Графики"
- Выберите переменные из списка (зажмите Ctrl для множественного выбора)
- Нажмите "Построить график"

### Вкладка "Возмущения"
- Просмотр графиков внешних факторов Fak1-Fak6

### Вкладка "Состояние системы"
- Лепестковая (радиальная) диаграмма всех 28 переменных
- Момент времени выбирается ползунком или кнопками контрольных точек (t₀, ¼, ½, ¾, конец)
- Синий полигон — состояние в выбранный момент, серый пунктир — начальное состояние, красный пунктир — максимумы переменных
- Точные значения (включая отрицательные) — в подсказке при наведении на вершину

## Ограничения

- Расчёт на интервале [0, 1] с шагом 0.05 занимает доли секунды (RK4, внутренний шаг 0.01)
- Значения характеристик гарантированно остаются в [0, 1] благодаря логистической форме уравнений (см. «Форма уравнений»)
