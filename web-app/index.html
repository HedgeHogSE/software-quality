Функции модели

В каждом слоте можно выбрать любую из 187 функций f1…f187 и изменить коэффициенты её многочлена. Значения по умолчанию взяты из лабораторной (F3, F5, F9, F48, F72, F81, F117), остальные функции тождественные. Изменения действуют со следующего запуска модели.

Функция Формула

Внешние факторы, влияющие на систему:

  • Fak1: Опыт разработчиков (t²)
  • Fak2: Опыт эксплуатантов (cos²)
  • Fak3: Трудоёмкость (sin(sin))
  • Fak4: Курс рубля (t)
  • Fak5: Репутация разработчиков (sin²)
  • Fak6: Репутация эксплуатанта (гармоническая)
Сначала запустите модель на вкладке «Параметры»
