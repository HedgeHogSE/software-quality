# Справочник математической модели качества ПО (ISO)

## Общая информация

Модель описывает динамику изменения 28 характеристик качества программного обеспечения во времени.
Формат системы дифференциальных уравнений:

```
du_i/dt = F_i(t, u(t), p),  i = 1, 2, ..., 28
```

## Функции модели (f1-f187)

Типы функций:

### 1. Линейная функция
```
f(x) = a*x + b
```
В Python: `linear_func(x, a, b)`

### 2. Квадратичная функция
```
f(x) = a*x^2 + b*x + c
```
В Python: `quadratic_func(x, a, b, c)`

### 3. Кубическая функция
```
f(x) = a*x^3 + b*x^2 + c*x + d
```
В Python: `cubic_func(x, a, b, c, d)`
