### 2. Проверка функций модели

Все функции f1-f187 реализованы с учётом трёх типов зависимостей:
- Линейная: f(x) = a*x + b
- Квадратичная: f(x) = a*x² + b*x + c
- Кубическая: f(x) = a*x³ + b*x² + c*x + d

Для функций без явного определения коэффициентов используется f(x) = x (a=1, b=0).
