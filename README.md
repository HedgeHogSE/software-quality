# Моделирование качества ПО на основе ISO

Приложение для моделирования качества программного обеспечения на основе системной динамики (модель ISO).

## Описание

Приложение реализует математическую модель качества ПО, описывающую взаимодействие 28 характеристик качества программного обеспечения. Модель основана на системе из 28 дифференциальных уравнений, учитывает 6 факторов внешних возмущений и позволяет моделировать динамику изменения характеристик во времени.

## Требования

- Python 3.11 или новее
- numpy >= 1.24.0
- scipy >= 1.11.0
- matplotlib >= 3.7.0

## Использование

После запуска приложения откроется окно с вкладками. Вот что делать на каждой вкладке:

### Вкладка "Параметры"

Здесь вы задаете начальные условия и параметры моделирования.

**Что нужно сделать:**

1. **Начальные значения переменных** (столбец "Значение") - это текущие значения 28 характеристик качества ПО на момент начала моделирования. Все значения должны быть положительными числами в диапазоне [0, 1].

   - `u5, u24, u25, u26, u27, u28, u54, u55, u56` - основные характеристики качества
   - `u107`...`u125` - дополнительные факторы, влияющие на модель

   **Как задать:** Нажмите кнопку "Установить по умолчанию" для загрузки начальных значений Реализации 1, или вручную введите значения в поля.

2. **Временной интервал** - настройки временного диапазона моделирования:
   - `Начало` (t_start) - начальный момент времени (обычно 0.0)
   - `Конец` (t_end) - конечный момент времени (обычно 1.0)
   - `Шаг` (step) - шаг дискретизации (рекомендуется 0.01)

   **Важно:** Если модель не сходится на интервале [0,1], попробуйте уменьшить его до [0,0.1].

3. **Запуск моделирования** - нажмите кнопку "Запустить модель" для расчета динамики характеристик.

### Вкладка "Графики"

Здесь отображаются результаты моделирования - динамика выбранных характеристик во времени.

**Что нужно сделать:**

1. **Выберите переменные** из списка слева (можно выбрать несколько, удерживая Ctrl или Shift)

2. **Нажмите "Построить график"** - на графике появятся линии для выбранных переменных

3. **Интерпретация графика:**
   - По оси X: время (от t_start до t_end)
   - По оси Y: значение характеристики качества (от 0 до 1)
   - Каждая линия показывает, как меняется одна характеристика во времени
   - Чем ближе значение к 1, тем лучше показатель качества

4. **Инструменты навигации:**
   - Масштабирование (круглая линейка)
   - Перемещение (стрелки)
   - Сохранение графика (иконка дискеты)

### Вкладка "Возмущения"

Эта вкладка показывает внешние факторы, влияющие на модель качества ПО.

**Что здесь отображается:**

1. **Список возмущений** - описание 6 факторов внешней среды:
   - `Fak1` - Опыт разработчиков программного комплекса
   - `Fak2` - Опыт работы эксплуатационного персонала
   - `Fak3` - Трудоёмкость разработки ПО
   - `Fak4` - Курс рубля по отношению к доллару
   - `Fak5` - Деловая репутация разработчиков
   - `Fak6` - Деловая репутация эксплуатирующей организации

2. **Графики возмущений** - отображение изменения каждого фактора во времени
   - Все значения Fak_i(t) лежат в диапазоне [0, 1]
   - Изменения возмущений влияют на скорость изменения характеристик качества

**Назначение возмущений:** Эти факторы моделируют внешние условия, которые влияют на процесс разработки и сопровождения ПО. Например, низкий опыт разработчиков (Fak1) может замедлять улучшение качества ПО.

### Вкладка "Состояние системы"

Здесь можно посмотреть точные значения всех 28 характеристик качества в конкретные моменты времени.

**Контрольные точки (5 штук):**

| Точка | Время | Описание |
|-------|-------|----------|
| 1 | t = 0.00 | Начальный момент |
| 2 | t = 0.25 | Первая четверть интервала |
| 3 | t = 0.50 | Вторая четверть (середина) |
| 4 | t = 0.75 | Третья четверть |
| 5 | t = 1.00 | Конечный момент |

**Как читать таблицу:**
- Каждая строка соответствует контрольной точке
- Каждая колонка (u5, u24, ..., u125) показывает значение конкретной характеристики
- Значения ближе к 1.0 означают лучшее качество
- Различия между точками показывают динамику изменения системы

## Как работать с приложением - пошаговая инструкция

**Сценарий 1: Первый запуск**

1. Запустите приложение
2. Перейдите на вкладку "Параметры"
3. Нажмите "Установить по умолчанию" для загрузки начальных значений
4. Убедитесь, что интервал [0.0, 1.0] и шаг 0.01
5. Нажмите "Запустить модель"
6. Перейдите на вкладку "Графики", выберите 3-5 переменных и постройте график
7. Перейдите на вкладку "Состояние системы" для просмотра значений в контрольных точках

**Сценарий 2: Сравнение разных реализаций**

1. Для каждой из 5 реализаций задайте свои начальные значения (из документа "Качество ПО.docx")
2. Запустите модель для каждой реализации отдельно
3. Сравните графики и таблицы состояний

**Сценарий 3: Исследование влияния возмущений**

1. Изучите формулы и графики возмущений на вкладке "Возмущения"
2. Попробуйте мысленно представить, как изменение каждого фактора повлияет на систему
3. Экспериментируйте с начальными значениями и возмущениями

## Математическая модель

### Переменные состояния (28 штук)
u5, u24, u25, u26, u27, u28, u54, u55, u56, u107, u108, u109, u110, u111, u112, u113, u114, u115, u116, u117, u118, u119, u120, u121, u122, u123, u124, u125

### Функции модели
- Линейная: f(x) = a*x + b
- Квадратичная: f(x) = a*x² + b*x + c
- Кубическая: f(x) = a*x³ + b*x² + c*x + d

### Функции возмущений
- Fak1(t) = t² + 1
- Fak2(t) = cos²(1.5πt - π/6) / 4 + 0.2
- Fak3(t) = sin(sin(πt - π/6)) / 2.5 + 0.3
- Fak4(t) = 2t - 1
- Fak5(t) = sin²(πt - π/6) / 2.5 + 0.3
- Fak6(t) = гармоническая функция в диапазоне [0.3, 0.7]
